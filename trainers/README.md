## Содержание пилота

21 обязательное действие и Д1–Д3 по желанию. Три микротемы, собственный план, девять пар на приёмы сжатия, два смысловых искажения, три собственных абзаца, слова-связки, объяснение приёма, редактура и выходная фраза. Исходные фрагменты перенесены из пользовательского прототипа и рабочего листа урока 13. Примеры 6 и 9 уточнены по содержательной сверке.

13 автобаллов — только подготовка. Ручная группа для абзацев 2–3 и пояснений имеет шесть критериев по одному баллу. До проверки её оценка `null`, а не ноль. Сумма из 19 и экзаменационная отметка не формируются. Свои планы, первый абзац, редактура и резерв сохраняются для комментария без автоматического оценивания.

Первая редакция сохраняется до открытия образца. Исправленный текст хранится отдельно; просмотр образца отмечается. При завершении сохраняется ещё одна редакция. Ответы можно скачать в читаемом текстовом файле или распечатать. Домашняя работа выполняется в своём темпе: подсказки о количестве минут и ограничения времени отсутствуют. В задании с собственным планом полный исходный текст показан прямо над полем ответа.

## Архитектура и новый урок

- `data/<subject>/<grade>/lesson-NNN.json` — весь предметный материал, этапы, ключи, подсказки, критерии и тексты вводного экрана.
- `schemas/lesson.schema.json` — JSON Schema 2020-12. Дополнительно `validateLesson` проверяет базовые условия при загрузке.
- `shared/engine.js` — переходы, профиль, самопроверка, редакции, итог.
- `renderers.js` — отдельные функции восьми механик; `scoring.js` — только закрытые ответы.
- `storage.js` — версия и профиль в ключе, восстановление и ошибки хранения.
- `results.js` — контракт `schema_version: 2`, задачи, навыки, подсказки, время, ручные группы и редакции.
- `submitter.js` — неизменяемая отправка и строгое подтверждение кабинета.

Названия мастерской, результата и вида письменной работы задаются полями `display.workspaceLabel`, `automaticNote`, `manualLabel`, `workHeading`, `scaleNote`. `display.draftNotice` сообщает о версии для просмотра. `material.sourceUrl` необязателен: для локального рабочего листа достаточно честной подписи источника в `material.attribution`. `revisionMode: "final-only"` сохраняет одну итоговую редакцию; без этого поля остаётся сценарий первой и исправленной редакций изложения. Текстовые выгрузки раскрывают соответствия и порядок словами, без технических ID.

Для стихотворного текста задать `material.format: "verse"`: переносы строк сохраняются в цитате, боковом тексте и полном тексте перед письменным ответом. `paragraphLabels` — заголовки фрагментов по порядку; `sourceLabel` — подпись ссылки; `glossary` — массив `{term, definition}`. Без этих полей прежние комплекты прозы работают как раньше.

Для нового урока скопировать JSON, задать собственные `id`, `version`, `subject`, `grade`, `lesson`, этапы, материал, `display` и задания. Держать ID заданий стабильными, не заменять опубликованную версию задним числом. `writingTaskIds` перечисляет абзацы для сборки, `finalTaskId` — поле окончательного текста. `manualGroups` задаёт общие критерии для нескольких ответов, не повторяя их максимум в каждом поле. Пилотный экран рассчитан на текстовые работы с ручной группой; произвольные контрольные пока не подключены.

Типы и ключи:

| Тип | Ответ ученика | Ключ |
|---|---|---|
| single-choice | ID | `answer`: ID |
| multi-choice, select-text | Массив ID | `answer`: точный набор без учёта порядка |
| order | Массив ID по порядку | `answer`: последовательность |
| match, classify | Объект ID → ID группы | `items`, `groups`, `answer` |
| fill | Объект ID поля → текст | `answers`: ID → допустимые строки |
| open-response | Свободный текст | Ключ не нужен, `points: 0`, `rubric` |

`skill` — стабильный код навыка, например `summary.microtheme`. Новый код добавляется в JSON без изменения движка. `errorTags` — список диагностических меток: первый элемент записывается при неверном закрытом ответе; пропуск получает `unanswered`. Подробная диагностика отдельных дистракторов — следующая доработка. `optional: true` исключает задачу из обязательного максимума.

`practice` разрешает самопроверку и подсказки. `independent` скрывает их до завершения; результат остаётся учебным клиентским расчётом. `control` намеренно не запускается: защищённые ключи, таймер и серверный подсчёт требуют отдельного подключения. Публичный JSON тренировочного урока не защищает ключи от просмотра.

Для задания ЕГЭ № 8 используется `fill` с полем `sequence` и `exam: {errors: [{letter, text}], sentences: [...]}`. На компьютере условия показаны в две колонки, на телефоне — последовательно. Полное условие также хранится в `context` для экспорта и последующего отображения в кабинете. Ключ — пятизначная строка в `answers.sequence`. `display.separateWrittenAnswers: true` собирает несколько самостоятельных ответов с заголовками в итог и редакции. `material.summaryLabel` позволяет назвать боковой материал «Памятка».

## Подключение журнала

`submitter.js` использует действующий Apps Script как транспорт: полный снимок `schema_version: 2` вложен в `answers.__trainer_v2`. Сервер распознаёт его до обработки старых уроков, проверяет версию комплекта и пересчитывает автобаллы по серверному JSON: максимум 13 для русского языка 9 класса, 10 для русского языка 7 класса 13 для «Полтавы» и 17 для синтаксического тренажёра 11 класса. Все ответы, редакции, подсказки и критерии сохраняются в YDB и Object Storage. Шесть ручных критериев выставляются в кабинете; отсутствие проверки отличается от проверенной работы с 0/6.

`collectorForLesson` разрешает отправку только зарегистрированной сервером пары ID и версии. Подключены `russian.9.lesson-013@1.0.0`, `russian.7.lesson-012@1.1.0` `literature.7.lesson-008@1.0.0` и `russian.11.lesson-014@1.0.0`. Неизвестные версии блокируются до POST. Добавлять новые версии в список можно только вместе с серверной регистрацией содержания и типов заданий.

Отправка считается завершённой только после строгой квитанции `schemaVersion: "kodislovo.collector-receipt.v1"`, `trainerSchemaVersion: 2`, `status: "accepted"`, `journal: "teacher"`, совпадающего `sourceSubmissionId`, непустого `submissionId` и `trainerGrading`. Повтор использует тот же ID и неизменённый снимок, не сбрасывает проверку учителя. После начала отправки до подтверждения доступен повтор; редактирование создаёт новую отправку только после подтверждения прежней. Предпросмотр не отправляется.

Числовые шкалы находятся отдельно в `trainerGrading.automatic` и `trainerGrading.manualGroups`. Для совместимости с действующим листом «Журнал сайта» поле `grading.earnedPoints` этой версии содержит подпись с двумя отдельными результатами. Общего итога из 19 нет. CSV кабинета тоже показывает шкалы отдельно. PDF старого формата для нового тренажёра отключён; ученик может скачать читаемый TXT или распечатать работу.

Действующая таблица маршрута `18.09.2026` используется как техническое место доставки; эта дата не является датой нового задания. Фактическое время записывается при отправке. Код Apps Script и секреты не менялись. Для обновления Google-отчёта после проверки учителем используется существующий запуск синхронизации отчёта; автоматического фонового обновления нет. Основной результат всегда находится в кабинете.

Действующий транспорт ограничивает JSON ответов 40 000 символами. При превышении ученик получает сообщение и может скачать всю работу или сократить её перед отправкой. Имена и работы никогда не помещать в Git. Подключение следующего комплекта требует регистрации его версии и механик в серверном обработчике; одного клиентского JSON для отправки недостаточно.

## Проверка и каталог

`node --test tests/*.test.js` запускает проверки старых механизмов и нового движка. Браузерный сценарий: `PLAYWRIGHT_MODULE` — путь к установленному Playwright; `TRAINER_BASE` — адрес локального сервера; `node tests/trainer_pilot.browser.cjs`. Проверить 360, 768, 1366 px, клавиатуру, две личности, перезагрузку, сохранность редакций и отсутствие ложного подтверждения отправки. Проверка текста — по материалам урока, не по автоматически восстановленному ключу ФИПИ.

Ссылка `trainers/play.html?subject=russian&grade=9&lesson=13` добавлена в карточку 9 класса каталога русского языка. В каталог также добавлена мастерская тезисного плана 7 класса. «Полтава» доступна в каталоге литературы. Синтаксический тренажёр 11 класса доступен на главной странице и в каталоге русского языка.
