# Причастные обороты · 11 класс · Урок 16

Путь: `trainers/russian/participial-phrases/`. Отдельная механика разметки, перенесённая из утверждённого локального тренажёра без изменения содержания. Основной текст: И. С. Тургенев, «Лес и степь», фрагмент 219 слов; источник указан на странице. Проверка использует ключ учителя: 6 определяемых слов, 6 полных оборотов, 7 стрелок и грамматических форм. Преобразования придаточного нет. Четыре предложения редактора сохраняют утверждённые варианты; объяснения оценивает учитель.

Страница использует общие `assets/css/ui.css`, `assets/js/theme.js`, `assets/js/student-class.js` и `trainers/shared/student-entry.js`. Вход через существующую форму фамилии, имени и класса обязателен. Черновик определяется версией материала и нормализованным профилем ученика; «Сменить ученика» открывает форму повторно. Эта форма разделяет локальные черновики, не является аутентификацией.

TXT, JSON, печать и передача файла содержат профиль и все ответы. JSON другого ученика не подставляется под текущий профиль; для переноса нужно сменить ученика. Ранее созданный локальный JSON без профиля разрешено импортировать под введённым именем. Web Share API передаёт TXT выбранному пользователем приложению; отмена сохраняет ответы. При отсутствии поддержки или ошибке скачивается TXT для прикрепления в MAX. Выбор приложения и чата выполняется самим учеником. Приём результатов в учительский кабинет для этого урока не подключён.

Фамилии учеников и реальные работы не хранятся в исходниках и не отправляются на сервер этой страницей. Публичный ключ служит тренировочной самопроверке.

Локальная проверка: запустить обычный статический сервер из корня репозитория и выполнить `node tests/participial_phrases.browser.cjs` с `TRAINER_BASE` и `PLAYWRIGHT_MODULE`, если пути отличаются от установленных Windows-путей. Проверки используют только условные тестовые профили и не отправляют ничего в MAX.
